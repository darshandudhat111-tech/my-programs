# 🚀 React Installation & Setup

## Step 1: Create React Project

```bash
npm create vite@latest MyProject
```

Choose:

```
Framework : React
Variant   : JavaScript + React Compiler
Which linter to use? : ESLint
Install with npm and start now? : Yes
```

---

## Step 2: Move into Project

```bash
cd MyProject
```

---

## Step 3: Install Dependencies

```bash
npm install
```

---

## Step 4: Install React Router

```bash
npm install react-router-dom
```

---

## Step 5: Start Development Server

```bash
npm run dev
```

Open your browser:

```
http://localhost:5173
```
